# 使用与部署指南

[返回产品首页](../README.md) · [English overview](../README.en.md)

安装和首次启动见[快速开始](../README.md#快速开始)。本页说明操作方式、恢复边界及部署注意事项。

## 连接主机

在连接表单中填写主机、用户名、端口（默认 `22`）和目标工作组，按需提供密码、私钥文件、私钥口令或 TOTP。提交后，在目标组中创建终端窗口。

主机管理器读取的是**运行服务的用户所能访问的 OpenSSH 配置**，默认 `~/.ssh/config`，不是浏览器电脑上的配置。可通过 `--sshconfig='/absolute/path/ssh_config'` 更换文件。

识别出的主机可以填入表单、直接打开，或多选后批量打开到指定工作组。桌面端支持逐项选择和 `Shift` 连选；切换工作组后可继续分配主机。SSH 配置中的私钥路径由后端读取和使用，前端不展示私钥内容。

## 工作组与终端

工作组支持新建、重命名、拖动排序、调整宽度、全屏和固定终端清单。终端可以跨组拖动、改名、调整高度、最大化、重新连接或关闭。删除工作组时，已有终端会移到相邻组，而不是随组删除。

默认布局根据组数排列：单组占满主面板，两组各占一半，三组采用左侧整高半屏与右侧上下堆叠；更多分组向右横向延伸。组内终端列表与终端历史分别滚动。

**工作台模式**适合并排查看多个终端；**聚焦模式**通过带组色的标签切换主终端，侧栏提供连接、设置、快捷操作、广播控制与历史。开启输入同步后，主终端中的输入会同步到该组当前广播范围内的其他终端；切换终端或执行命令前，请确认同步状态与目标范围。

## 命令广播

每组独立设置广播范围：

| 范围 | 实际行为 |
| --- | --- |
| 全部 | 向组内所有已连接终端发送，即使只有部分终端被勾选。 |
| 已选 | 只向组内选中的已连接终端发送；未选择任何终端时阻止发送，不回退为全组。 |

广播输入框支持命令与常用控制键，包括 `Ctrl+C`、`Ctrl+D`、`Ctrl+Z`、`Ctrl+L`、`Tab`、`Enter` 和 `Esc`。空输入发送相当于发送 `Enter`，不会新增历史记录。是否自动回车可在系统设置中调整。

每组最多保存 100 条去重后的广播命令，并提供常用只读 Linux 诊断命令候选。`Tab` 接受补全，方向键浏览历史与候选，`Esc` 关闭候选并恢复草稿。点击候选只填入输入框，不直接执行。

范围与终端选择保存在当前浏览器中；关闭终端或将其移至其他组，会清除该终端原有的选择。**分组上传不受广播范围控制。**

## 上传文件

终端标题栏的上传入口用于单机上传；工作组上传入口会将同一文件依次上传到该组所有已连接终端。上传窗口会逐台显示目标目录，可分别改为其他绝对路径。

| 项目 | 行为 |
| --- | --- |
| SSH 上传 | 依赖目标主机的 SFTP 服务。 |
| 当前目录 | Bash、Zsh、Fish 可通过临时 OSC 7 提示符钩子上报目录，不修改 shell 配置文件。 |
| 目录回退 | 未收到目录上报时，SSH 回退到远端主目录，本机终端回退到启动目录。 |
| 同名文件 | 默认不覆盖；覆盖需要在上传窗口中明确勾选。 |
| 大小限制 | 单文件默认 100 MiB，可在系统设置或通过 `--maxupload` 调整。 |

Windows 本机 shell 不支持此处的 OSC 7 目录跟踪，上传目录会回退到启动目录。上传前请核对路径，尤其是分组上传。

## 会话恢复与数据存储

| 场景 | 恢复结果 |
| --- | --- |
| 刷新页面，服务进程及会话仍存活 | 恢复窗口并重新接入存活会话。 |
| 服务重启，工作组已固定 | 根据保存清单重建终端窗口，不会保留旧服务进程中的会话。 |
| 重建的 SSH 窗口需要敏感凭据 | 显示“需要重新认证”，补充凭据后在原窗口中连接。 |
| 手动关闭终端窗口 | 断开对应 SSH 会话或结束本机终端进程。 |

固定分组的清单随终端新增、关闭、移动、重命名和高度调整而更新。本机终端及不依赖已保存敏感凭据的 SSH 终端可自动重新连接；密码、TOTP、上传的私钥内容和私钥口令不会写入恢复清单的浏览器存储。

组级“重连失败终端”只处理能够直接重连的错误状态窗口，不会对已连接、连接中或等待重新认证的窗口发起批量认证。

工作组布局、固定清单、广播范围、主题等保存在当前浏览器的 `localStorage` 中，不会自动跨浏览器同步。广播历史单独保存在 `wssh-broadcast-history`，删除工作组时一并删除。**命令历史可能包含敏感文本，请勿将密码或令牌直接写入广播命令。**

## 本机终端、外观与快捷键

“本机终端”打开的是**服务端用户的 shell**，与 SSH 终端共用分组、窗口、日志和关闭逻辑。Linux / macOS 使用 PTY；Windows 使用 ConPTY（pywinpty），需要 Windows 10 1809+，可按安装情况选择 CMD、Windows PowerShell 或 PowerShell 7。

明暗主题调整工作区、分组、面板和弹窗，终端内部配色保持原有风格。主题选择会在刷新后保留。顶栏与连接侧栏支持自动收缩和固定展开。

| 操作 | Windows / Linux | macOS |
| --- | --- | --- |
| 打开连接表单 | `Ctrl+Shift+C` | `Command+Shift+C` |
| 打开主机管理器 | `Ctrl+Shift+H` | `Command+Shift+H` |
| 打开系统设置 | `Ctrl+Shift+,` | `Command+Shift+,` |
| 切换面板固定展开 | `Ctrl+Alt+P` | `Command+Option+P` |
| 切换当前组广播范围 | `Ctrl+Alt+S` | `Command+Option+S` |

系统设置中可以重新绑定、清空或恢复快捷键，并调整终端字号、高度、广播回车行为和断开确认等选项。“日志”入口展示操作日志；终端标题栏显示的是 **WebSocket 连接延迟**，不是目标主机的 SSH 网络延迟。

## 启动参数

```bash
# 仅允许从服务所在机器直接访问
wssh --address=127.0.0.1 --port=8888

# 使用指定的 SSH 配置文件
wssh --address=127.0.0.1 --sshconfig='/absolute/path/ssh_config'

# 调整连接数与单文件上传上限
wssh --address=127.0.0.1 --maxconn=50 --maxupload=100

# 指定默认字符编码
wssh --address=127.0.0.1 --encoding=utf-8

# 查看全部参数
wssh --help
```

`--maxconn` 默认 20，限制单客户端存活连接数；`--maxupload` 默认 100，单位 MiB。已保存的系统设置会在启动时加载，可能覆盖这些命令行初始值。

直接执行不带地址参数的 `wssh` 并非仅监听回环地址；首次使用建议保留上面的 `--address=127.0.0.1`。

## 远程访问与部署

该服务可以发起 SSH 连接、使用服务端 SSH 配置，并打开服务端本机 shell。请以最小必要权限运行，仅向可信用户提供访问，**不要把 SSH 连接表单当作产品页面的登录认证**。

对外提供访问时，应通过受控网络或带认证的反向代理接入，并配置 HTTPS。认证需覆盖页面、HTTP 接口和 WebSocket；仅启用 HTTPS 不等于具备访问控制。

使用已通过可信渠道核对的主机密钥文件，并启用严格校验：

```bash
wssh --address=127.0.0.1 --port=8888 \
  --policy=reject --hostfile='/absolute/path/known_hosts'
```

`--policy` 的可选值为 `reject`、`autoadd`、`warning`，代码默认值为 `warning`。不要为解决连接报错而盲目信任未知主机密钥。

Nginx 反向代理需要支持 WebSocket Upgrade。以下**仅为代理片段，不包含入口认证与 HTTPS 配置，不能单独作为公网部署方案**：

```nginx
location / {
    proxy_pass http://127.0.0.1:8888;
    proxy_http_version 1.1;
    proxy_read_timeout 300;
    proxy_set_header Upgrade $http_upgrade;
    proxy_set_header Connection "upgrade";
    proxy_set_header Host $http_host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-Proto $scheme;
}
```

程序也支持通过 `--certfile`、`--keyfile` 配置 TLS，HTTPS 监听端口由 `--sslport` 指定，默认 `4433`。使用证书时仍应显式设置监听地址，并单独配置访问控制。

仓库保留了 [Dockerfile](../Dockerfile) 和 [Compose 配置](../docker-compose.yml)，可供自行构建。容器中的“本机”指容器，不是宿主机；SSH 配置与私钥也必须在容器内可访问。容器方案的网络、卷挂载、访问控制和本机 shell 可用性需要按实际环境验证，首页快速开始以 Python 安装为准。

## 开发与检查

从仓库安装依赖后，可以直接运行入口脚本：

```bash
python -m pip install -r requirements.txt
python run.py --address=127.0.0.1 --debug
```

静态 JS / CSS 修改后刷新页面；非调试模式下，模板或 Python 修改需要重启服务。`--debug` 仅用于开发。

运行测试：

```bash
python -m unittest discover tests
```

项目同时保留 [README.rst](../README.rst) 作为当前 `setup.py` 使用的包介绍。包名仍为 `webssh`，命令仍为 `wssh`；不要把安装本仓库与从包索引安装同名上游项目混为一谈。
